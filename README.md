# 🌐 인터랙티브 온톨로지 튜토리얼 (Interactive Ontology Tutorial)

이 프로젝트는 사회복지 실무자 및 초보자를 위해 **온톨로지(Ontology)** 개념을 시각적이고 인터랙티브하게 학습할 수 있도록 제작된 웹 기반 튜토리얼입니다.

기존의 복잡한 IT 기반 예제 대신, **사회복지 현장(가계도, 자원망, 서비스 분류 등)**의 생생한 예시를 통해 온톨로지의 핵심 원리를 쉽게 이해할 수 있도록 돕습니다.

## 🎯 주요 학습 내용 (10단계 마스터 클래스)

1. **트리플(Triple)의 이해**: 주어-동사-목적어로 연결되는 지식의 최소 단위
2. **추론(Inference) - 가계도**: 입력된 데이터(부모)를 바탕으로 새로운 지식(조부모, 형제)을 자동 발견
3. **지식에 질문 던지기 (SPARQL)**: 지식 그래프에서 조건에 맞는 대상자 검색
4. **복지서비스 계층 구조 (Taxonomy)**: 클래스와 서브클래스의 상속 관계 검증
5. **사례관리 네트워크 (속성)**: 대칭(Symmetric) 및 역방향(Inverse) 속성을 통한 관계 자동 완성
6. **중복자 데이터 융합 (SameAs)**: 분산된 클라이언트 데이터를 동일 인물로 선언하여 통합
7. **전달체계의 꼬리물기 (이행적 속성)**: 이행적(Transitive) 속성을 활용한 상위 기관 추론
8. **오류 차단하기 (도메인과 레인지)**: 지식망의 논리적 충돌을 자동으로 검사 및 차단
9. **나만의 복지자원망 만들기**: 직접 노드와 엣지를 추가하며 자유롭게 실습하는 공간
10. **지능형 검색**: 프로그램에 필요한 특정 자원(예: 인적 자원)만을 똑똑하게 걸러내기

## 🛠 사용된 기술
- **HTML5, CSS3, Vanilla JavaScript**: 가벼운 Single Page Application(SPA) 구성
- **[vis-network](https://visjs.github.io/vis-network/)**: 인터랙티브한 지식 그래프(Knowledge Graph) 및 네트워크 시각화 렌더링 엔진
- **Pretendard Font**: 깔끔하고 가독성 높은 UI를 위한 웹 폰트 적용

## 🚀 실행 방법
이 프로젝트는 별도의 서버 구축 없이 브라우저에서 바로 실행할 수 있습니다.
